NEXTPULSE PRODUCTIONS WEBSITE

Files:
- index.html  Main website
- style.css   Responsive styling
- script.js   Mobile menu

DEPLOY TO NAMECHEAP:
1. Log in to your Namecheap account.
2. Open cPanel -> File Manager (or use FTP).
3. Open the public_html folder for nextpulseproduction.com.
4. Upload index.html, style.css and script.js.
5. Make sure index.html is directly inside public_html.
6. Visit https://nextpulseproduction.com

EMAIL:
The contact form currently opens the visitor's email client using:
hello@nextpulseproduction.com
Change this address in index.html if you want a different inbox.
